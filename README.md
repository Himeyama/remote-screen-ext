# Remote Screen

Windows のデスクトップを、同じネットワーク上の PC やタブレットのブラウザに表示する WinUI 3 アプリです。

## ビルド

Windows 10 (バージョン 2004) 以降と .NET 8 SDK が必要です。実行する Windows PC には .NET 8 Desktop Runtime と ASP.NET Core Runtime が必要です。

```powershell
.\build.ps1
```

スクリプトは起動中の Remote Screen を閉じ、アプリのビルド出力を消去してから `bin` に出力します。同梱ドライバーは、削除されたファイルや変更があるファイルを復元します。ビルドが成功すると、更新版の Remote Screen が起動します。

x64 では [Virtual Driver Control 25.7.23](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.7.23) を取得し、SHA-256 を検証して `bin\VirtualDisplayDriver` に同梱します。2 回目以降はプロジェクト直下に保存した ZIP を使用します。配布時は `bin` フォルダー全体を渡してください。ドライバーを含めずにビルドする場合は `.\build.ps1 -SkipVirtualDisplayDriver` を使います。

## 複製

1. Windows アプリで「複製」を選び、「共有するディスプレイ」から画面を選んで「共有を開始」を押します。初期選択はメインディスプレイです。
2. 同じネットワーク上の端末で、Windows アプリに表示された共有リンクを開きます。アドレスの候補が複数ある場合は、端末と同じネットワークの Wi-Fi または有線 LAN のアドレスを選びます。
3. ブラウザの映像をタップまたはクリックし、右上に現れる全画面アイコンを押すと全画面になります。タッチ画面では映像を下にスワイプすると通常表示に戻ります。Windows アプリの「共有を停止」で配信を終了します。

Windows ファイアウォールの確認が表示された場合は、使用中のプライベートネットワークで Remote Screen の接続を許可します。接続には TCP 8765 を使用します。「この PC で開く」で、LAN を経由せずに同じ Windows PC 上でも表示を確認できます。

アプリ下部に共有状態が表示されます。共有中は、選択したディスプレイと現在閲覧しているブラウザの接続数も表示されます。共有する画面を切り替えるには、一度共有を停止して画面を選び直してください。

## 拡張

1. 物理ディスプレイを追加するか、Remote Screen の「拡張」から「仮想ディスプレイドライバーをセットアップ」を開き、Virtual Driver Control で「Install Driver」を選びます。インストールには管理者権限が必要です。セットアップボタンが表示されないビルドでは、画面に表示される[公式の入手先](https://github.com/VirtualDrivers/Virtual-Display-Driver)の手順で導入します。
2. Windows の「設定 → システム → ディスプレイ」で、追加したディスプレイの設定を「表示画面を拡張する」にします。
3. Remote Screen で「拡張」を選び、「一覧を更新」して共有するディスプレイを選択します。「共有を開始」を押し、端末のブラウザで共有リンクを開きます。
4. Windows 側でウィンドウを追加ディスプレイへ移動します。`Win + Shift + ← / →` でも移動できます。

## 初回の接続と次回以降

- 初回は Windows アプリに表示された共有リンクを開くか、ブラウザで接続先の `/` を開いて6文字の認証コードを入力します。
- 次回からは、Windows アプリで共有を開始したあと、同じブラウザで同じアドレスの `/` を開くと投影できます。たとえば `http://192.168.1.50:8765/` です。認証は365日間保存されます。ブラウザの Cookie を消した場合や接続先の IP アドレスが変わった場合は、新しい認証コードを入力します。

「承認済み端末をすべて削除」を押し、確認画面で「すべて削除」を選ぶと、保存済みの接続承認が解除されます。共有中は配信も停止します。次回は新しい共有リンクまたは認証コードで接続してください。

映像とマウスポインターを WebSocket で配信します。Windows では対応するディスプレイを DirectX の Desktop Duplication で取り込み、取得間隔は最短約 8ms です。利用できない場合は Windows GDI を使います。画面は長辺 1920 ピクセルに収め、最初に全領域を送り、以降は変化した 256 ピクセル角の領域を zlib で可逆圧縮して送ります。受信側が遅れた場合は、最後に表示した状態から最新の画面までに変わった領域だけを送ります。LAN 内の HTTP 通信なので、信頼できるネットワークで使用してください。
